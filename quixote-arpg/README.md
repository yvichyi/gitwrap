# 风车与疯狂 · Windmill Madness

一款以《堂吉诃德》为原型的**手机横屏 3D 动作打怪升级游戏（ARPG）**。主角是沉迷骑士小说、分不清现实与幻想的落魄骑士，一路上和风车巨人、施咒的魔法书、受惊的羊群、镜中骑士，以及魔法师弗雷斯顿周旋。

核心卖点是**疯狂值**：越癫狂，攻击与暴击越高，但防御与稳定性越差。把堂吉诃德的精神状态直接变成战斗机制。

纯前端实现：Three.js（已 vendor 到仓库，无构建步骤）+ 原生 ES Modules。所有模型都是程序化生成的低面数几何体，不依赖外部素材。

## 运行

```bash
cd quixote-arpg
npm start            # 启动 http://localhost:8080（ES Modules 需要 http，直接双击 index.html 无法加载）
```

手机上打开同一局域网地址，横屏游玩。也可以把整个目录部署到任意静态托管（GitHub Pages、Nginx 等）。

## 测试

```bash
npm install                 # 仅 e2e 需要 playwright（开发依赖）
npm test                    # 单元测试：战斗规则、边界情况、存档、剧本式通关
npm run test:e2e            # 浏览器端：5 种横屏比例 + 竖屏提示 + 触控/键盘/后台暂停/存档续玩
```

e2e 默认访问 `http://localhost:8080/index.html`，可用 `GAME_URL` 指定地址、`CHROME_PATH` 指定 Chromium。截图写入 `tests/e2e/out/`（已忽略）。

## 操作

| 功能 | 触控（横屏） | 键盘 |
| --- | --- | --- |
| 移动 | 左半屏按下即出现的动态摇杆 | WASD / 方向键 |
| 攻击（三段连招） | 攻击 | J |
| 重击（按住蓄力，松开释放） | 重击 | K |
| 闪避（无敌帧） | 闪避 | Space / 左 Shift |
| 格挡（刚举盾 0.2 秒内被击中 = 完美格挡，反击） | 格挡 | L |
| 突刺（穿透） | 突刺 | Q |
| 冲锋 | 冲锋 | E |
| 盾击（反弹魔法书的书页） | 盾击 | R |
| 风车旋风（疯狂 ≥ 60 时可用） | 旋风 | F |
| 暂停 | 右上角「暂停」 | Esc / P |

右上角「左手 / 右手」一键切换按键侧；「地图」展开小地图与目标。设置中可调按键大小（70%–140%）、透明度（30%–100%）、显示策略，并可拖动调整每个按键的位置，位置以屏幕高度为单位保存，在 16:9 到 20:9 之间保持比例。

## 玩法循环

```
进入关卡 → 按波次战斗（击杀、闪避、完美格挡、拾取掉落）→ 升级（属性点、天赋点）
        → 强化角色（分配属性、选择 build 分支、穿戴装备）→ 下一关 → … → 击败弗雷斯顿，通关
```

- **3 个关卡**：拉曼恰平原（风车与羊群）→ 风车山丘（镜子里的骑士）→ 哥特城堡（魔法师的终局）。
- **存档**：角色成长（等级、属性、天赋、装备、背包）实时保存；关卡从开始处重来。切后台自动暂停并存档，回来后停在暂停菜单。
- **等级上限 15**，升级获得 3 点属性与 1 点天赋。

## 主角

| 项目 | 数值 |
| --- | --- |
| 初始属性（力量 / 敏捷 / 体魄 / 意志） | 5 / 5 / 5 / 5 |
| 生命 | 60 + 体魄×10 + 等级×6 + 装备 |
| 攻击 | 武器伤害 + 力量×2 + 等级×1.2，再乘攻击% |
| 暴击 | 基础 5% + 敏捷×0.4%，暴击伤害基础 150% |
| 护甲减伤 | 护甲 / (护甲 + 120)，护甲 = 体魄×0.6 + 装备 |
| 移速 | 4.6 m/s ×（1 + 敏捷×1%） |
| 疯狂值 | 0–100（装备可加上限） |
| 闪避 | 0.42 秒，0.03–0.30 秒无敌；冷却 0.7 秒 |
| 格挡 | 减伤 55%（装备可加），正面 130° 扇形；耐久 100，破防后硬直 1.2 秒 |
| 硬直阈值 | 生命上限 18%（疯狂越高越低，最多降低 40%） |

**疯狂值**（线性插值，满值为 100）：

| 数值 | 满值效果 | 阶段 |
| --- | --- | --- |
| 攻击 | +50% | 清醒 0–29 / 痴狂 30–69 / 癫狂 70–100 |
| 暴击率 | +20% | |
| 受到伤害 | +35% | |
| 硬直阈值 | −40% | |

获取：轻击命中 +1.5、重击命中 +3、格挡 +2、完美格挡 +6、击杀普通 +2、精英 +10、施放技能 +5、受伤每 10 点 +1。脱战 3 秒后每秒衰减 1.2。

**技能**（冷却受装备「冷却缩减」影响，上限 35%）：

| 技能 | 冷却 / 消耗 | 效果 |
| --- | --- | --- |
| 长矛突刺 | 4.5 秒 | 前方直线 4.2 m、宽 1.1 m，2.2 倍伤害，穿透 1 个目标，前冲 1.8 m |
| 冲锋 | 7 秒 | 直线冲刺 7 m（撞墙/障碍停下），1.6 倍伤害并击退 3.5 m，冲撞期间免疫硬直 |
| 盾击 | 5 秒 | 120° 扇形 2.2 m，1.2 倍伤害，硬直 1 秒，反弹扇形内的魔法书书页 |
| 风车旋风 | 消耗 60 疯狂 | 持续 2.4 秒，半径 3.2 m，每 0.4 秒 0.9 倍伤害，移速 50%，免疫硬直 |

**连招与取消后摇**：三段轻击（1.0 / 1.15 / 1.6 倍，第三段硬直击退）；招式结束前可以接下一段；收招期可以闪避或释放技能取消。在**起手阶段**取消会被判为「假动作」，镜中骑士会因此露出破绽。

**一套可识别的预警**：所有危险攻击都会先在地面画出红色（致命）或黄色（施法/引导）的预警形状，时长 0.35–1.2 秒，然后才判定伤害。

## 成长与 build

- **属性**：力量（攻击）、敏捷（攻速、移速、暴击）、体魄（生命、护甲）、意志（疯狂获取）。
- **装备**：五个槽位（长矛、圆盾、头盔、胸甲、圣物）。品质：普通（0 词缀）→ 稀有（2）→ 史诗（3）→ 传说（4，部分有独特效果）。掉落权重：

  | 来源 | 普通 | 稀有 | 史诗 | 传说 |
  | --- | --- | --- | --- | --- |
  | 普通怪 | 60 | 28 | 9 | 3 |
  | 精英 | 30 | 40 | 22 | 8 |
  | Boss（三件） | 0 | 30 | 40 | 30 |

- **三条 build 分支**（第一个天赋点选择流派，之后按顺序解锁，流派不可切换）：
  - **长矛突刺流**：穿刺（突刺伤害 +15%、穿透 +1）→ 骑兵冲撞（冲锋后 1.5 秒暴击 +15%）→ 骑士誓言（暴击伤害 +25%，暴击回复疯狂）
  - **圆盾守护流**：铁壁（格挡效率 +15%）→ 反击之盾（完美格挡反击 ×2）→ 不朽之墙（耐久 +50，格挡回血）
  - **癫狂骑士流**：疯魔（疯狂上限 +20，癫狂阶段攻击 +20%）→ 狂热吸血（癫狂阶段命中回血）→ 风车之怒（旋风 +1 秒，消耗 −20）
- **独特装备**：「堂吉诃德的旧长矛」（穿透 +1，突刺冷却 −1 秒，每次命中额外疯狂）、「桑乔的木盾」（格挡 +10%，完美格挡回血 4%）。

## 代码结构

```
index.html / styles.css        页面、HUD 与屏幕的结构与样式（安全区、横屏、无横向滚动）
src/main.js                    入口：读档、固定步长主循环、事件分发、后台暂停、横竖屏提示
src/config/                    全部数值与内容（balance.js 战斗数值；content.js 装备、流派、关卡）
src/sim/                       纯逻辑（不依赖 DOM / Three.js，可在 Node 中测试）
  world.js                       一场战斗：刷怪、波次、伤害结算、掉落、命中盒与弹幕、关卡结束
  player.js                      骑士的动作状态机：连招、取消、假动作、闪避无敌帧、格挡与完美反击
  enemies.js boss.js             怪物 AI 与预警（telegraph）系统；弗雷斯顿的阶段与魔力石
  companion.js                   桑乔
  stats.js items.js progression.js   属性汇总、疯狂阶段、装备生成、经验与天赋
  session.js save.js             关卡流程；存档（容错读写，localStorage 出错不影响游戏）
src/render/                    Three.js 渲染：场景、镜头、程序化模型、粒子与伤害数字
src/input/                     键盘 + 触控：动态摇杆、按键布局与编辑、左右手切换
src/ui/                        HUD（血量、疯狂、冷却、Boss 条、横幅、小地图）与菜单（角色、设置、暂停、结算）
vendor/three/                  Three.js 0.186.1 的 ES 模块构建（MIT，附 LICENSE）
tests/unit/                    单元测试（node:test）
tests/sim/bot.js               剧本式玩家，用于平衡检查
tests/e2e/                     Playwright 端到端检查
scripts/serve.js               静态服务器
```

**设计约束**：sim 层不读取 `Math.random`，全部随机走种子化的 `rng`，同一种子的战斗可复现；所有命中判定与预警同源（`geometry.js`），保证「看见的形状就是判定的形状」；渲染只读取 sim 状态，不反向修改。

## 测试覆盖

- **连续闪避**：五次连续翻滚，每次都在无敌帧内躲开命中；冷却期内再按闪避会被忽略；无敌帧结束后的命中会正常结算。
- **多怪同时受击**：四个敌人同一帧命中各自结算，同一帧的伤害互不吞没；无敌帧内四击全部闪避；一次挥击对同一目标只结算一次。
- **格挡**：正面减伤、背后不挡、0.2 秒内完美格挡并反击、第二次格挡不再完美、耐久耗尽破防硬直。
- **每个怪物的弱点**：风车正面/侧面/背后系数；魔法书吟唱被打断不出弹；羊群撞障碍眩晕并吃额外伤害；镜中骑士被假动作骗到后露出破绽；风车扫击正前方安全；Boss 阶段只触发一次、转阶段无敌、魔力石护盾与碎裂。
- **成长**：经验与升级、属性点与天赋顺序、装备替换与背包上限、疯狂阶段与倍率。
- **存档**：往返一致、损坏/版本不符/越界数据被忽略、存储抛错不影响游戏、设置值被钳制。
- **关卡流程**：波次全部刷出后清场一次；死亡只结束一次；暂停时世界时间不推进；最后一关进入通关；重来一关保留角色成长。
- **剧本式通关**（`tests/sim/bot.js`，固定种子）：第一关完整跑通，并且一个成型角色可以从第一关打到通关（经过三阶段 Boss）。

运行 `npm test` 可以看到全部用例。

## 已知限制

- **性能**：在无 GPU 的 headless Chromium（软件 WebGL）里只跑到约 13 fps，所以**没有在真机上验证 30 fps**。画质档位「流畅 30」会把渲染上限压到 30 fps、像素比限制到 1，并减少粒子；真机帧率需要在目标机型上实测。
- **没有音频**：目前没有音效和音乐。
- **关卡内存档**：存档保存角色成长，不保存关卡中的状态；关卡从开始处重来。
- **平衡**：脚本玩家（会闪避、格挡、拿装备、加点）在 12 个固定种子上 7 次通关，失败全部发生在第二关（风车山丘：镜中骑士与魔法书的交叉火力）。这是目前最需要真人试玩来调的地方，脚本的反应远不如真人灵活，我没有按脚本的数据去削弱第二关。
- **AI 寻路**：没有寻路网格，怪物直线移动并沿障碍滑动；障碍很多的场地会显得笨拙。
