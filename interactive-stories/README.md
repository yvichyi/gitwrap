# Interactive Story / 互动叙事

## 牛奶袋中的回声 · Echoes Inside A Bag Of Milk

A short interactive narrative about a difficult trip to buy milk, told through the guiding voice inside the protagonist’s mind. Open [牛奶袋中的回声.html](牛奶袋中的回声.html) in a browser to play.

一段关于走出房间、穿过走廊并买到牛奶的互动叙事。通过主角脑海中的引导声音展开；打开上方单文件即可体验。
