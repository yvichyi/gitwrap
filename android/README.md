# Science Gallery for Android

This is an **additive** native Android shell for the 57 standalone HTML experiments in `../science-collection/`. The original Python gitwrap CLI and the web gallery are unchanged.

## Implementation

- Java Activity + Android WebView, Android API 24+, target API 35.
- Ships the checked-in gallery as Android assets; no server, account, or runtime network connection required for gallery content.
- Uses `androidx.webkit.WebViewAssetLoader` to load HTML and relative paths at `https://appassets.androidplatform.net/assets/`, rather than enabling unrestricted file access.
- Enables JavaScript, DOM storage and user-gesture-gated media playback for local interactions.
- Opens external hyperlinks in another Android app, instead of navigating the embedded WebView away from the offline gallery.
- Supports system Back navigation and WebView state restoration.

## Build

Open the `android/` folder in Android Studio, or install JDK 17, Android SDK 35, Gradle 8.9 and run from the repository root:

```sh
gradle -p android :app:assembleDebug
```

Output: `android/app/build/outputs/apk/debug/app-debug.apk`.

The GitHub Actions workflow at `.github/workflows/android-apk.yml` builds this APK on pushes and pull requests that change Android or gallery files, then uploads an artifact named `science-gallery-debug-apk`. In GitHub, open **Actions → Android APK → latest successful run → Artifacts** and download the ZIP containing the APK.

## Scope and verification

The Android shell is intended to demonstrate repeatable cloud APK builds, not a Play Store release. The debug APK uses a development signing key generated by the build environment. Physical-device testing, all 57 experiments, and store-compliant release signing must be verified separately. Changes to the gallery under `science-collection/` are picked up by the next build.

For source attribution and experiment limitations, see `science-collection/README.md` and its accompanying docs. This wrapper does not alter the original work's licensing status.
