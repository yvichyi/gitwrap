# 澜音

接入网易云音乐的第三方 Android 播放器：竖屏是常规音乐 App，横过来就是 QQ 音乐风格的横屏播放页。

> 当前进度：**M18 重绘**。M18 之后去掉了「影」主题（之前选了影的会回到墨），机、游、酸、暮、霓五个主题正按[新样稿](design/concepts/README.md)重做，暮（孔版工作台）、霓（雨夜开车的像素画）、机（胡桃木柜里的组合音响）、游（整屏 1-bit 游戏）和酸（传单墙）都已经做完；接着把剩下的墨、报、格、点也按同样的标准升级，墨（文房书案：宣纸、挂轴山水、印章、砚台唱片和毛笔唱臂）、报（一份真报纸：新闻纸、活字压印、报眼、分类广告、半调印刷的唱机照片）、格（瑞士设计工作室：同心圆音乐会海报、色票、带构造线的图稿）和点（透明后盖的小机器：电路板、无线充电线圈、排线、电池和螺丝，灯带随音乐亮）已经做完，九个主题都升级完了。扫码登录网易云音乐后，可以听每日推荐、私人 FM、我喜欢的音乐、自己的和收藏的歌单、排行榜、歌手、专辑和音乐云盘，搜索单曲 / 歌手 / 专辑 / 歌单；能看和写评论，管理歌单，下载离线听，上传到云盘，播放记录会同步到网易云；有 45 个音效预设，有状态栏歌词。一共九个主题，首页、「我的」、竖屏和横屏播放页、列表页都按主题的「媒介」排版（M11–M14）。这一版（M18）换了**图标**（毛笔写的「澜」，脚下一方朱印「音」），**动效**重做了一遍（各主题换页都改成顺滑的曲线，播放页下拉时跟着手指走，列表一行行浮上来，歌单头图随滚动退到后面、标题收进顶上的细栏），**机、影、游、酸、暮、霓**六个主题的歌单页、首页和「我的」大改，墨的竖排歌词不再有落单的字和横躺的英文，完整歌词里点空白处就回到封面。上一版（M17）补了日常最需要的几样：**定时关闭**（到点前半分钟渐弱，或者播完这首就停）、**歌词时间微调**（按歌记住，状态栏、词幕和桌面歌词跟着一起调）、**后台播放**引导（让系统不因省电停掉播放），以及设置里的**诊断**：卡顿、出错和闪退都记在手机上，可以导出一份去掉了账号信息的报告发给我。上一版（M16）加了**桌面歌词**：离开澜音后，正在唱的那句浮在其他应用上面，十个主题各有样子，可以拖动、锁定，快捷设置里有开关。上一版（M15）：搜索页一打开就有「最近搜过」和网易云热搜榜；长按一句歌词能做成分享卡片，卡片按主题画（书法条幅、霓虹招牌、孔版画、海报……）；评论、播放队列、输入框也各按主题画；换主题时，新主题从点的那张卡片处画一个圆展开；按下去的触感每个主题不同；暮的天空、墨的月亮、霓的街道跟着当地时间变；设置里有「减少动效」（系统关掉动画时自动打开）；状态栏歌词接上了词幕（Lyricon）；release 版可以用自己的密钥签名。完整路线见 [docs/PLAN.md](docs/PLAN.md)。

## 网易云音乐

App 直接连网易云（本地实现 eapi / weapi 加密，不经过任何服务器）：

- **登录**：扫码登录，二维码可以存到相册，再用网易云「扫一扫 → 相册」识别（同一部手机扫不了自己的屏幕）；也可以试「直接在网易云里打开」，或者在高级选项里粘贴 `MUSIC_U` Cookie。登录凭证用 Android Keystore 的密钥加密保存，不进备份，只发给网易云。
- **能听的**：首页的每日推荐、私人 FM（不想听的跳过会告诉网易云）、推荐歌单（登录前是热门歌单）、排行榜；「我的」里是我喜欢的音乐、创建和收藏的歌单、最近播放；歌手页（热门歌曲）和专辑页；搜索边打字边出结果，可以搜单曲、歌手、专辑、歌单。点哪首就从哪首开始播放整张列表。
- **播放**：歌曲到要播放时才去要播放地址（网易云的地址二十分钟左右就失效；它的音频节点有的只认 http、有的只认 https，连不上会自动换另一种再试），按设置里的「在线音质」要（默认无损，超清母带要 SVIP），没有就自动降一档；听过的歌存在「边听边存」缓存里（默认 1 GB，设置里可以改成 512 MB 到 4 GB），再听不用流量。没有版权或需要 VIP 的歌会提示原因并跳过。
- **后台**：Media3 播放服务，带通知栏、锁屏控制、蓝牙和耳机按键，拔耳机自动暂停，来电等情况自动让出声音。
- **歌词**：有逐字时间（YRC）的歌，扫色跟着每个字唱到的时刻走，而不是匀速扫过整行；其余用 LRC。翻译按时间对齐，网易云开头的作词作曲信息也会显示；加载中显示「歌词加载中」，纯音乐显示「纯音乐，请欣赏」。
- **搜索**：还没输入时，上面是本机「最近搜过」的词（最多 12 个，可以清空），下面是网易云的热搜榜（前三名用强调色，带网易云写的一句说明和热度），点一下就搜。打开了结果或在键盘上按了搜索，这次的词才记进「最近搜过」。
- **队列和「⋯」**：播放页和迷你条的队列按钮打开播放队列（点哪首跳到哪首，可以切播放模式）。播放页和每一行歌后面都有「⋯」：收藏、添加到歌单、下载、看评论、去歌手页或专辑页；在自己的歌单里还能把歌删掉，在云盘里能删文件（删除要点两次）。
- **歌单**：「我的 → 创建的歌单」最上面可以新建歌单（可以设成隐私）；自己的歌单右上角「⋯」能改名、删除；别人的歌单和排行榜可以「收藏」。
- **评论**：播放页的评论按钮上带着数量（「1w+」）。评论页分推荐、最热、最新，往下滑自动加载，点赞立刻生效（网易云不同意会退回去），点一条评论就是回复它。
- **下载**：在「⋯」里下载一首，或者在歌单、专辑、歌手页、每日推荐里「下载全部」。下载交给后台服务，通知栏有进度，退出 App 也会接着下；默认只在 Wi-Fi 下下载。下载完的歌播放时直接读本地，不用网。只能试听的 VIP 歌不会下载（不然存下的是 30 秒片段）。下载的文件在 App 自己的目录里，只在澜音里播放。
- **音乐云盘**：在「我的」里，显示用了多少空间，分页加载，能播放、能删除。点「上传」从手机里选歌（可以多选），一首一首传，页面上有进度；网易云已经有同一个文件的会「秒传」。歌名、歌手、专辑从文件标签里读。上传走网易云自己的对象存储，连接全程 https。
- **播放记录**：每首听满半分钟（或短歌的一半）就告诉网易云，账号的「最近播放」和「听歌排行」里会有在澜音听的歌；设置里可以关掉「同步播放记录」。「我的 → 最近播放」可以在「本机」和「网易云」（账号在所有设备上的记录）之间切换；「听歌排行」有最近一周和所有时间。
- **分享歌词**：在歌词里长按一句（或在「⋯」里选「分享这句歌词」），会生成一张 4:5 的卡片，样子跟着当前主题：墨是一开册页（绢裱的宣纸上一幅水墨山水，这句歌词像题画诗一样从右往左竖写在山上的天空里，后面一小列写歌名和歌手，盖「澜音」和「听」两方印，角上一枚「清音」闲章，翻译写在下面的绢边上），霓是挡风玻璃上的抬头显示（像素画的雨夜高架，歌词投在玻璃上，下面是中控屏的歌名和像素封面），暮是贴在切割垫上的孔版画（封面印成三色网点，歌词叠印在白边上，铅笔签名，盖一枚橡皮章），格是一张瑞士海报（上半是这首歌的同心圆海报和黑白封面，下面是最粗的黑体歌词），点是 LED 点阵屏，机是拉丝铝面板上的荧光屏（青色像素字），下面贴着手写歌名的磁带侧标，报是一块别着回形针的剪报（报头、压印的大标题、署名、网点配图，上面一排套准十字和色标），游是一位色的游戏对话框（两色抖动的封面在上面），酸是贴在墙上的一张黑传单（网点复印的封面、斜贴的青柠色胶带上写着这句、笑脸贴纸）。可以交给系统的分享面板，或者存进相册的「Pictures/澜音」（Android 10 以上不需要存储权限）。
- **红心**：播放页的红心直接同步到网易云「我喜欢的音乐」。
- **音质**：点播放页上的音质标签（横屏在顶栏）就能换，正在放的歌从当前位置接着放；设置里也能改默认音质。
- **音效**：播放页的音效按钮（或设置里的「音效」）。45 个预设分四组——**曲风**（流行、摇滚、软摇滚、金属、爵士、蓝调、古典、民谣、乡村、国风、嘻哈、R&B、电子、舞曲、俱乐部、Techno、派对、雷鬼、斯卡）、**场景**（LiveHouse、音乐厅、教堂、KTV、录音棚、3D 环绕、8D 环绕、迷幻电音、车载、耳机、夜间）、**人声 · 低音**（人声、清澈人声、重低音、超重低音、低音+高音、高音增强、响度补偿、柔和）、**复古**（黑胶、电子管、卡带、Lo-fi、收音机），每个都有一句说明。经典曲风的均衡曲线来自 VLC 沿用多年的预设（源自 Winamp），按 0.6 的力度用；场景和复古是把均衡和效果组合起来调的。十段均衡器可以直接拖，拖了预设就变成你自己的曲线；滑块有低音增强、环绕、混响、空间大小，「更多效果」里还有回声、动态压缩、温暖（电子管式饱和）、复古窄频、唱片底噪和 8D 旋转。音效在澜音里用软件处理（不依赖手机厂商的音效接口），耳机和外放都有效，加了限幅不会爆音；选「原声」时音频原样通过，一个字节都不改。
- **跟随封面取色**：播放页的强调色（按钮、进度条、歌词高亮，霓的按键和进度）取自正在放的封面：挑封面里最鲜明的主色，保留色相，再调亮度直到在主题背景上看得清（对比度按 WCAG 4.5:1），换歌时慢慢过渡。黑白灰的封面保持主题原色。设置里可以关。
- **状态栏歌词**：正在唱的那句显示在状态栏。魅族 Flyme 直接支持（歌词写进媒体通知的 ticker，带魅族的两个标志位）；澎湃、ColorOS 等装了 LSPosed 的手机，用 Lyric Getter（配合「墨·状态栏歌词」）或 SuperLyric 模块也能读到；Android 16 以上再加一枚「实时活动」胶囊：胶囊放不下整句，就把一句按标点切成六个字以内的小段，跟着唱到哪里换哪一段，下拉通知能看到整句和歌名。设置里可以关，胶囊也可以单独关；系统关掉了澜音的实时活动时，设置里会提示去打开。装了 LSPosed 模块**词幕（Lyricon）**的手机，澜音会把整首歌的歌词（带逐字时间和翻译）交给它，再在播放、暂停、拖动和切歌时告诉它播放到哪里，由它自己对时间，所以平常播放时不用一直发消息；没装这个模块的手机上什么也不会发生。
- **桌面歌词**：在设置里打开（第一次要允许「显示在其他应用上层」），离开澜音后，正在唱的那句会浮在其他应用上面，逐字扫色，下面一行是翻译或下一句；没有歌词时显示歌名。点一下出现控制条：上一首、播放 / 暂停、下一首、字小一点 / 大一点、锁定、关闭；按住上下拖能挪位置，位置和字号都会记住。锁定后点不到它，点击直接落到下面的应用（Android 12 起系统要求这样的窗口稍微透明一点才放行点击，所以锁定后会淡一点），在快捷设置里加一个「桌面歌词」开关就能随时开关、解锁。回到澜音时自动收起，暂停几秒后也会收起。默认是「轻」：只有字，带一圈淡淡的深色描边，在白色页面和深色照片上都看得清，不挡后面的内容；唱到的字按主题上色（墨是朱红、霓是发光灯管、暮是晚霞渐变、格是荧光黄、点是白色点灯、机是荧光屏的青色像素字、报是红笔、游是像素字体加纸色、酸是荧光青柠），字体也跟着主题。设置里可以改成「卡片」，可以关掉第二行，也可以调不透明度（30%–100%）；出现和收起时都是淡入淡出。「卡片」的样子：墨是两根木轴之间展开的一段手卷（宣纸裱在绢上，「澜音」朱印打头），字从灰色写成墨色，下面跟着一笔干笔；霓是暗墙上的招牌，唱到哪里灯管亮到哪里；暮是一条贴着的纸，唱到的字印成粉色，末尾一个套准标记，字随唱随染成晚霞色；格是带硬投影的粗框标签，黄色荧光笔一个字一个字划过去；点是黑色点阵胶囊；机是拉丝铝条上嵌的荧光屏，唱到的字亮起来；报是一条带双线的新闻纸，红笔在唱过的字下面划线；游是对话框，字一个一个打出来，唱完出现 ▼；酸是一张黑色传单，唱过的字变成荧光青柠。
- **定时关闭**：在正在播放那首歌的「⋯」里，选 15 / 30 / 45 / 60 / 90 分钟，或者「播完这首」。到点前半分钟音量慢慢降下去，然后暂停，音量自动恢复。定时期间播放页底栏有一个月亮和剩余时间，点一下可以改或取消。
- **歌词时间微调**：遇到整首歌词偏早或偏晚，在正在播放那首歌的「⋯」里选「歌词时间微调」，看着当前唱的那句，按「提前 / 推后 0.1 秒、0.5 秒」调。只对这首歌，会记住；页面里的歌词、状态栏歌词、词幕和桌面歌词都跟着一起调。
- **后台播放**：设置里会显示系统是否可能为了省电在后台停掉澜音，点一下去允许；小米、OPPO / 一加、vivo、华为 / 荣耀、魅族、三星各自还有一份后台名单，会提示在哪里打开。
- **诊断**：设置最下面。每一帧画了多久按「页面 + 主题」记下来（掉帧按安卓自己的标准：超过一帧时间的两倍；超过 100 毫秒算严重卡顿，会列出时间和页面），加载失败和播放出错记下是什么错（不记是哪首歌），闪退会在退出前写下堆栈。都只存在手机上；点「导出诊断报告」才会生成一份文字报告交给系统分享，报告开头是版本、手机型号和主要设置，Cookie、token 之类会被去掉。可以清空重新记录。
- **存储**：设置里能看到「边听边存」、封面和头像、下载各占多少，可以分别清空；「边听边存」的上限改了立刻生效，超出的先删最久没听的。

各主题的小节标题和页面标题也有自己的记号：点是红色点阵编号加虚点引线，机是「A1」标签和型号铭牌，报是粗细两道线下的「第一版」，游是 ▶ 光标，酸是一张张贴纸和青柠色的字，暮是套准标记和油墨色条，霓是会通电的霓虹字。

所有主题共用一套规则：四级字号、页边距、一屏一个强调色、同一族自绘线性图标（线宽随主题变化）。每个主题都有四种生成封面构图，推荐歌单不会一排都是同一张图。「点」的 Doto、「机」和「酸」的 Space Mono、「酸」的 Archivo Black、「霓」的 Tilt Neon、「暮」的 DM Serif Display 和龙藏体（按常用字裁剪过）、「游」的缝合像素字体都是 SIL Open Font License 的开源字体，打包在 `app/src/main/res/font`，版权和许可见 [licenses/FONTS.md](licenses/FONTS.md)。图标里的「澜」取自志莽行书（Zhi Mang Xing）、「音」取自 Noto Serif SC Black，也都是 OFL 字体，只把这两个字的轮廓转成了矢量路径，没有打包字体文件。

九个主题里「点」「酸」「霓」只有深色，「格」「游」只有浅色。主题之外，还可以单独选**播放页样式**：旋转黑胶（默认）、方形封面、沉浸歌词、复古卡带。

### 动效

设置里的「减少动效」会让背景、唱片和装饰动画都停下来，霓虹不再闪烁，换页只是淡入淡出，也更省电；系统里关掉了动画（开发者选项或无障碍里的「移除动画」）时会自动这样。平时也省着用：暂停后播放页背景会慢慢停住；装饰动画每秒最多更新约 100 次，所以 120Hz 的屏幕隔一帧才重画一次背景；霓的雨和亮着的窗户合成几条路径一起画（每帧的绘制调用从三四百降到六七十到九十）。有一个测试量每个主题播放页背景每帧的开销（CPU 渲染时间、绘制调用数、分配的内存），超标就失败。

- 点迷你播放条，它会展开成播放页（容器变形），唱片从缩略图长成大唱片。**下拉**时播放页跟着手指一比一往下走，边走边缩小一点、圆角越来越大；往下一甩，或者拉过屏幕的五分之一就收起，不到就弹回去（以前拉的距离是按顶栏的高度算的，轻轻一拉就收起，播放页自己却只挪了一点）。系统返回手势让播放页跟手缩小。
- **换页**：每个主题的换页方式不同（见「各主题的表现形式」），但都用快起慢收的曲线，退场比进场短；以前游的一格一格、霓的闪两下看起来像掉帧，去掉了。
- **列表**：歌单、搜索结果、「我的」里的歌单第一次出现时一行一行浮上来，往下滚到的行不再等；首页各块第一次进来时也依次浮上来，回到首页不重播。歌单的头图在往下滚时比列表慢一点退到后面并淡出；标题滚出屏幕后，顶上滑下一条细栏，带返回键、标题和歌单的操作。
- 唱片有惯性：播放时加速转起，暂停时慢慢停下；唱臂带回弹落下。
- 歌词逐行像波浪一样跟上，当前行略微放大并卡拉 OK 式扫色；字号可以在设置里选小 / 中 / 大（默认 18sp：中文字比同字号的英文更满，主流 App 的歌词也大多在 16–18sp）；歌词大小只听这个设置，不跟系统字体大小走，不然系统字号调大的手机上歌词会大得离谱；可以拖动歌词浏览，松手后自动回到当前行，点某一行跳到那里。
- **滑动切歌**：左右滑动唱片（竖屏、横屏都行）或迷你播放条切到上一首 / 下一首，唱片跟手滑走，下一张从另一边滑进来；用按钮切歌也是同样的方向动画。上一首按钮和多数播放器一样：歌放了 3 秒以上先回到开头。
- 竖屏播放页从上到下：「正在播放 · 歌单名」居中的标题栏，唱片和三行歌词（上一句、当前句、下一句，点一下进入全屏歌词），歌名和歌手，整宽的进度线（时间在线下方，数字等宽不跳动），播放控制，最下面一行是音质标签、歌词和旋转按钮。
- 打开播放页时，标题栏、歌词、歌名、进度、控制按顺序升起；播放时唱片边缘在听到的每一拍荡出一圈涟漪（墨是墨线，霓是发光管，格是方框；没有明显鼓点的歌就很少），暂停时唱片轻轻退后一点。
- 竖屏的唱片 / 封面外圈也有一圈频谱（以前只在横屏有），背景跟着低音、中音、高音和鼓点动（见上面主题表），播放键也跟着节拍：墨荡出墨线，暮的橡皮章晕开油墨圈，霓的琥珀色按键外亮起像素光，格的方块跳一下，点的圆盘外一圈小灯随音量亮起，机的橙色按键发光，报的红版印得更偏，游的 A 键被按一下，酸的圆盘外闪出一圈星号。
- 频谱和涟漪跟着真实的声音走：解码出来的音频先经过一个分析器（每 512 个采样做一次 1024 点 FFT，折成 32 个频段），结果按音频自己的时间戳存着，再按扬声器此刻在放的位置去取，所以画面对的是正在听到的声音，而不是提前几百毫秒解码出来的那部分。
- 拍子是一张「拍网」，像人跟着打拍子：把全频段的起音（底鼓、军鼓、和弦变化、唱出的字都算，高频算得少）攒成最近 6 秒的起音曲线，每 0.1 秒从它的自相关里估一次速度（同时看一倍和半倍的位置，偏向 120 BPM，取最近五次的中位数），再找拍点落在哪里最能对上起音（越近的拍越重要），然后按这张网落拍，每次新估计只把网轻轻拉过去一点（锁相环），差太多才跳过去。所以底鼓空掉的那一拍也有拍子，踩镲和装饰音不会被当成拍。歌刚开始的三秒还没有网，先用底鼓起音顶上；音乐没了律动两秒左右就放掉这张网。用 GTZAN 的 60 段录音和 librosa 的参考节拍比，±70 毫秒内的 F 值从 0.44 提到 0.66。
- 画面跟拍：涟漪、播放键和地平线的闪光在下一拍之前就收住（快歌短、慢歌长），霓的车道线和酸的地面网格每两拍滚过一格，并在拍点上对齐；酸的星星轮流在拍点上闪。以前背景里「速度 × 时间」的写法会让网格、云、雾在音量变化时整段跳位，放得越久跳得越远，现在都改成按速度累加位移。
- 歌词：有逐字时间的歌按字扫色。只有逐行时间的歌（网易云不少歌只有这种），先用整首歌估出演唱速度（每秒唱几个字或词，取各行的第 70 百分位，限制在合理范围内），再按每行的字数算出这一行大约唱多久，在这段时间里扫完；行尾到下一行之间的间奏不再被算进去，所以不会一下子亮完，也不会扫得比人声快。换行时不弹跳。状态栏歌词用同一套时间。没有歌词时分三种情况说：网易云标了纯音乐的是「纯音乐，请欣赏」，网易云没有这首歌词的是「暂无歌词」，没加载下来的是「歌词没能加载，点一下重试」。
- 切歌时，歌名和歌手顺着切歌方向滑出、新的滑进来，新歌的歌词从下往上依次浮现；当前句亮起时会微微上浮。上一首 / 下一首按钮按下会往对应方向推一下，播放模式图标切换时会弹一下。
- 拖动进度条时，歌词跟着手指走到那一句，松手才真正跳过去。
- 横屏是「顶栏、舞台、控制栏」三段：顶栏左边是收起按钮和歌名（像窗口标题），右边是音质、评论、音效、红心和旋转；舞台每个主题不一样（见上面「横屏舞台」），多数有一行歌单来源和下一首。**点舞台空白处切换全屏**，再点一下回来；不点就一直保持带顶栏和控制栏的样子（有些主题的舞台配着它们更好看），不会自己进全屏。全屏时顶栏和控制栏收起，舞台放大，底部只剩一行歌名和时间，加一道进度细线。横屏时隐藏系统栏；也可以在设置里打开「进入播放页时自动横屏」。
- 纯音乐会显示「纯音乐，请欣赏」，超长的歌名、歌手名会省略，长歌词会换行且放大后不出界。
- 系统字体调大时（很多手机默认就偏大）界面跟着放大，卡片和按钮会随文字长高，放不下的文字会省略，不会被切掉；截图测试里有一套 360dp 宽、1.3 倍字号的全页面检查。

## 编译

需要 JDK 17+。

```bash
./scripts/setup-android-sdk.sh      # 安装 Android SDK 到 ~/android-sdk，并写 local.properties
./gradlew assembleDebug             # → app/build/outputs/apk/debug/app-debug.apk（未压缩，约 60 MB）
./gradlew assemblePreview           # → app/build/outputs/apk/preview/app-preview.apk（R8 压缩，约 7 MB，debug 签名，可直接安装）
./gradlew testDebugUnitTest         # 单元测试
./gradlew recordRoborazziDebug      # 在 JVM 上渲染界面截图 → app/build/outputs/roborazzi/（sweep/ 里是每个主题、每种深浅色的全部页面）
NETEASE_LIVE=1 ./gradlew testDebugUnitTest --tests '*NeteaseLiveTest'   # 对真实的网易云服务器跑一遍（匿名注册、二维码、搜索、歌词、榜单、拉一段真实音频）
```

### 正式签名的 release 版

`./gradlew assembleRelease` 默认产出未签名的 `app-release-unsigned.apk`。要用自己的密钥签名，先生成一个密钥库（只做一次，**密钥库和密码都不要提交到仓库，也要自己备份好**，丢了以后就没法用同一个签名升级）：

```bash
keytool -genkeypair -keystore ~/lanyin-release.jks -alias lanyin -keyalg RSA -keysize 4096 -validity 10000
```

然后在项目根目录（和 `settings.gradle.kts` 同一层）写一个 `keystore.properties`（已经在 `.gitignore` 里）：

```properties
storeFile=/home/你/lanyin-release.jks
storePassword=……
keyAlias=lanyin
keyPassword=……
```

或者用环境变量 `LANYIN_KEYSTORE`、`LANYIN_KEYSTORE_PASSWORD`、`LANYIN_KEY_ALIAS`、`LANYIN_KEY_PASSWORD`（适合 CI）。之后 `./gradlew assembleRelease` 就会产出签好名的 `app/build/outputs/apk/release/app-release.apk`（R8 压缩，APK 签名 v3 方案；minSdk 是 29，不需要 v1）。release 版的包名是 `io.lanyin.player`，和 preview 版（`io.lanyin.player.preview`）、debug 版（`io.lanyin.player.debug`）可以同时装着。

如果 Maven Central 限流（HTTP 429），可以改走 Google 的镜像：

```bash
MAVEN_MIRROR=google ./scripts/setup-android-sdk.sh
export ROBOLECTRIC_REPO_URL=https://maven-central.storage-download.googleapis.com/maven2
```
