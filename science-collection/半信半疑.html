02 计算说明 / MODEL NOTES

一个线性高斯的世界，
和它的边界。

预测、称重、修正、验收——滤波器每一步只做这四件事。三行公式之外，还有一页它不打算假装的边界。

预测 / PREDICT

x− = F x，
P− = F P FT + Q

匀速模型加白噪声加速度：不确定性沿速度方向被拉长，未建模的风把它吹得更宽。
增益 / GAIN

K = P−HT(H P−HT + R)−1

两份方差的折算：R 大信模型，Q 大信测量；数值上用 Joseph 形式更新保对称。传感器越钝越信模型，模型越谦逊越信测量。
验收 / AUDIT

NIS = yTS−1y ~ χ²(2)

每步更新的标准化残差：NIS 的期望是 2，2σ 覆盖约 86.5%。
模型边界

这是概念实验，不是传感器方案。

页面没有计算非线性（EKF / UKF）、关联噪声、多目标与数据关联、RTS 平滑，也不模拟真实传感器的漂移与野值。真值与测量都由确定性随机数生成——同一条轨迹可以逐位重放，每个数字都能对账。

因此，结论只适合比较「信多了 / 信少了」的定性差异；页面给出的米数、百分比不构成任何工程选型依据。
