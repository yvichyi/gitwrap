组合博弈 · 一个局面值多少

两个人在一个局面上轮流走，谁走不了谁输。绝大多数棋类靠搜索判断输赢， 但有一类局面可以像数字一样加起来：把两个局面并排放，值就是两个值之和。 这一页从零实现这套算术——精确的二进分数、支配与绕道、左右停手、温度、Sprague–Grundy—— 再把 32,766 根 Hackenbush 杆、17 个 Domineering 棋盘、8,191 个逐日构造出来的数 全部算一遍，和 OEIS 与文献逐条对账。结论是：值确实存在，但它常常不是数。

壹标尺：什么叫「一个局面值多少」

写一个局面为 {L | R}：L 是 Left 能走到的局面，R 是 Right 能走到的。 Left 想要大的值，Right 想要小的值。空局面 { | } 是 0。 一个白送的一步是 {0 | } = 1，反过来是 { | 0} = −1。 下面这张表是本页的标尺：所有别的数字都要和它对齐。

规范化：把写法不同、值相同的局面压成同一个

两个局面「相等」是指：无论和什么局面相加，结果都一样。 Conway 的定理说，这只取决于它们的规范形式——同一个值只有一种规范写法。 规范化的两步是：消掉被支配的选项、绕过可逆的选项。

贰数：一天一天造出来

Conway 的构造是按天进行的。第 0 天只有 { | } = 0。 第 1 天可以拿已有局面当选项，造出 −1 和 1。第 2 天造出 −2、−1/2、1/2、2。 第 n 天出生的数正好 2ⁿ 个，累计 2ⁿ⁺¹ − 1 个 —— 这不是巧合，是每一对相邻数之间恰好插一个新数。

肆热：不是数的那一半

最简单的非数局面是 {a | −a}（记作 ±a）：Left 能把值推到 a，Right 能推到 −a。 它比任何小于 a 的数都大、比任何大于 −a 的数都小，但和 0 又互不支配 —— 这叫模糊。 它的均值是 0，温度是 a：温度量的是"谁先走谁占多少便宜"。 温度 0 意味着局面对走子顺序无所谓 —— 这时它要么是数，要么是"数加一个星"（{a|a} = a + *， 那已经不是开关了）；温度越高，先手优势越大。

温度是怎么量出来的：冷却

每冷却一步，双方都要为"该我走"付 t 的代价：G_t = { G^L_t − t | G^R_t + t }。 当 t 小的时候 Left 的停手值大于 Right 的（先手有便宜）；t 一旦涨到温度，两个停手值相等， 再涨就反过来了。所以温度就是两条停手曲线相交的那个 t。

伍平局：两边走法一样的时候

如果两个玩家的走法规则完全相同（无偏博弈），这套"值是数"的算术就退化了： 值被压缩成一个整数 —— Sprague–Grundy 值。它是"能走到哪些值"里最小的非负整数。 判断一堆无偏局面的胜负只要一个异或：nim-sum = 0 则先手必输。
