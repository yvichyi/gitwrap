壹两条路

一台最简单的干涉仪：一比特态 → 分束器（H）→ 只给其中一条路加相位 φ → 再合束（H）→ 测。 振幅是复数，所以两条路合起来是 (1 + e^{iφ})/2，取模方得到 P(0) = cos²(φ/2)。相位一转，概率就跟着走 —— 这就是全部量子怪异的来源。

|0⟩ --H--> (|0⟩ + |1⟩)/√2 --相位 e^{iφ} 加在 |1⟩--> (|0⟩ + e^{iφ}|1⟩)/√2 --H--> [(1+e^{iφ})|0⟩ + (1−e^{iφ})|1⟩]/2 P(0) = |1 + e^{iφ}|² / 4 = cos²(φ/2) 经典模型：P(0) ≡ 1/2，与 φ 无关

相位 → 概率 曲线是闭式，点是实测频率

相量加法器 拖动看两条路怎么相加

统计误差的 1/√N 律 量子与经典各一条

凭什么说"经典看不到 φ" 对照实验

把同一个装置里的光子换成一个只带概率的经典粒子：第一次分束器让它以 1/2 走臂 0、1/2 走臂 1， 相位 φ 照旧加在臂 1 上，第二次分束器再 50/50 混合。

结果是一条平线：P(0) 恒等于 1/2。相位在概率里没有位置 —— 加多少都一样。 这不是"经典模型不够好"，而是"相位"这个量在概率论里根本没有对应物。

贰N 条路

两缝只是一个特例。把缝数加到 N、每条缝的相位线性增长，用离散傅里叶变换把振幅合起来， 得到的不是更宽的条纹，而是越来越窄、越来越高的峰。峰高恒为 1，峰宽 ∝ 1/N —— 这就是光栅为什么能把光分成颜色。

a_k = e^{ikφ}/√N （第 k 条缝的振幅） b_j = (1/√N) Σ_k a_k · e^{2πijk/N} （DFT：把振幅合起来） P_j = |b_j|² = sin²(N x/2) / (N² sin²(x/2))， x = φ + 2πj/N Σ_j P_j = 1 （DFT 是酉的 ⇒ 概率严格守恒）

端口 0 的概率 vs 相位 N = 2 / 4 / 8

叁知道的代价

干涉不是免费的。要条纹，就必须无法知道光子走了哪条路。让探测器稍微知道一点， 条纹就稍微模糊一点；让它全知道，条纹就彻底消失。这个交易有一条精确的汇率。

探测器：|d₀⟩ = |0⟩，|d₁⟩ = cosθ|0⟩ + sinθ|1⟩ P(路径 = 0) = (1 + cosθ·cosφ)/2 ⇒ 可见度 V = cosθ 最优猜路径的成功率 = (1 + sinθ)/2 ⇒ 可区分度 D = sinθ V² + D² = 1 （等号只在探测器是纯态时成立）

V 与 D 交换位置 θ 从 0 到 π/2

(V, D) 落在单位圆上 这就是那个等号

擦除器：知道探测器读数之后，条纹又回来了 拖 θ 看三条线

不分类、把探测器丢掉之后的 P(路径=0)。对比度就是 V = cosθ。

只保留探测器读数为 0 的那些事例。对比度是 2cosθ/(1+cos²θ) ≥ V。

肆整体与局部

纠缠不是"两个粒子之间有一根看不见的线"，而是一个更简单的事实： 整体的态是纯的，局部的态却是满的。取任何一个真子集、把剩下的自由度求和掉， 剩下的那个密度矩阵就变成了最大的混合态 —— 而整体一点信息都没丢。
