声学 · 受迫振动与阻尼共振

共振听证

一台被正弦驱动的阻尼弹簧振子，正在左耳里推，右耳里响。没有人给你看频响曲线——你的耳朵就是唯一仪器：拖动大旋钮连续扫频，靠响度隆起、扫掠时的短暂拍动和两耳间的相位差，找出振幅失控的那个频率；然后盲听估计这峰有多胖。找到峰只是第一关，听出品质因数 Q 是第二关。

三块基石 · 这件展品敢让你只凭耳朵判读的理由

下面的每个数字都出自固定参数的离线标定：峰位与半高宽来自闭式解的解析式与数值二分，对账证据来自逐样本合成的真跑。页面只复算与对账，不携带手写的结论。

第一块是稳态闭式解：m x″ + c x′ + k x = F₀ sin(ωt) 的稳态是 A(ω) = (F₀/k)/√((ω₀²−ω²)² + (2βω)²)、φ(ω) = atan2(2βω, ω₀²−ω²)——峰位 ω₀√(1−2ζ²)、峰高 1/(2ζ√(1−ζ²)) 全是解析事实，不需要数值模拟去猜。第二块是逐段精确合成：你听到的不是近似滤波，而是把闭式解逐段按状态匹配地取值——扫频时的 ω_d 衰减振铃因此是真的，它与受迫分量相拍，拍率 |f−f₀| 过峰时先慢到零再变快。第三块是同频不生拍：稳态响应与驱动力频率相同，两耳各自听到的是同一频率的纯音——所以稳态里没有拍可听，拍只出现在扫掠的暂态里；这就是为什么这台装置要你扫频，而不是停在一处苦听。

自检：启动即跑，随每次刷新重算。

模型边界 · 在哪里诚实

半高宽口径。峰位与 Q 不是近似公式，而是按定义数值求解：峰位取解析式 f₀√(1−2ζ²)（三档 ζ ≤ 0.15 远离 1/√2 退化）；半高宽是 A(ω)² = A_max²/2 的两个真根，各以固定 80 轮二分、不提前退出——所以 Q = f峰/(f₂−f₁) 与教科书近似 1/(2ζ) 在甲档差到 4.5%，本作以数值定义为准并如实显示两者。

相位线索的适用边界。人耳对双耳相位差的锁定在约 1.5 kHz 以下可用，三档 f₀（220/330/440 Hz）全部设在此范围内；扫掠拍线索依赖振铃寿命（约 2/β，甲档约 10 毫秒），所以它只在你快速扫过峰附近时以「短暂嗡一亮」的方式出现——本作不假装它是稳态里无穷持续的拍。

声画纪律。判读期间，频响曲线、响应包络、真值峰位一律不上屏：示波屏只画驱动力（形状恒为正弦，零信息），读数只给频率与档位名（ζ、f₀ 不显示——否则 Q 直接可算）。真值只在提交判读后的复盘里揭示。耳朵是判读仪器，不是装饰。

无声环境降级。实时音频依赖浏览器 AudioContext；无声或无授权环境下（含无头访问），驱动按钮只会把状态改成文字说明，不出错、也不向控制台报错。此时判读轮仍可提交，但会如实记为「无声轮」——不计入各档通过数，页面绝不假装你听过了。离线对账走 OfflineAudioContext，不需要任何音频设备。

记分册与隐私。成绩存于浏览器本机 localStorage（键名固定，最多 200 条，新的挤出最旧的），断网可用；隐私模式写不进去时自动降级为内存账本，本轮内照常记账、关闭即失——降级状态在「记分册」一行如实标注，绝不假装跨会话。
