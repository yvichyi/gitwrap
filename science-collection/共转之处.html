03 / 读懂这五处

平衡，不等于安稳。

在共转坐标里，探测器相对两颗主天体保持静止。这个平衡由几种作用共同维持；把探测器轻轻推开，才看得出它是否会回来。

Ⅰ

三个点，落在一条线上

L1 夹在两星之间，L2 在次星外侧，L3 在主星背后。它们靠重力与旋转系中的离心效应抵消，却都对小偏移敏感。

Ⅱ

两个点，围出等边三角形

L4 与 L5 分别领先、落后次星约 60°。当较小天体质量分数低于临界值时，附近的小扰动可以保持有界；稳定并不意味着轨道不会振荡。

能量画出禁行边界

Jacobi 常数限制了探测器能够到达的区域。零速度边界上，速度刚好为零；边界封闭时，某些区域之间就暂时无法穿过。

这里的 μ 是次星质量占两星总质量的比例。L4、L5 在 μ < μR 时线性稳定；越过临界值后，它们也会不稳定。临界点本身是边界情形。

展开动力学方程与无量纲单位

旋转坐标中的运动方程

ẍ − 2ẏ = ∂Ω / ∂x
ÿ + 2ẋ = ∂Ω / ∂y

科里奥利项来自旋转坐标。两颗主天体位于 x₁ = −μ、x₂ = 1 − μ。

有效势与守恒量

Ω = ½(x² + y²) + (1 − μ)/r₁ + μ/r₂
C = 2Ω − ẋ² − ẏ²

r₁ = √((x + μ)² + y²)，r₂ = √((x − 1 + μ)² + y²)。可达区域满足 2Ω ≥ C，等号就是零速度边界。

04 / 模型边界

这是一个清楚而有限的宇宙。

两星沿圆轨道绕共同质心转动；第三个探测器质量可忽略。所有位置和时间都用双星间距与平均角速度归一化。

平面模型只描述二维运动，不含天体轨道偏心、其他行星摄动、光压、天体有限半径或轨道维持燃料。近距离奇点会停止积分。

屏幕轨迹由有限步长的数值积分产生；Jacobi 常数漂移是数值误差的读数。这里的稳定性是模型中的线性稳定判定，不是实际任务保证。
