逼近之极

连分数、丢番图逼近，与「一个数能有多难被逼近」

壹 · 一个分数能多接近一个无理数

Dirichlet 在 1842 年证明了：对任何无理数 α，都存在无穷多个分数 p/q 使 |α − p/q| < 1/q²。这不是一个"存在某个"的结论，而是一条尺子 —— 它说逼近误差可以掉到分母平方那么快。 问题是：哪些 p/q 做到了？连分数给出了答案，而且是穷尽的答案 —— 一个数的收敛子（连分数逐项截断得到的分数）恰好就是它最好的那批逼近。

下面这张图把 φ 的每一个收敛子画在双对数坐标上，并叠上 1/q² 参考线。 注意那些点不是在一条线上，而是在两级台阶之间交替 —— 因为 φ 的连分数 [1; 1, 1, 1, …] 全是 1，误差每两步才降一次。

φ 的收敛子误差 vs 分母 q（双对数），虚线为 1/q² 参考

φ 的收敛子表

递推是 p_k = a_k·p_{k−1} + p_{k−2}，分母同样。全部用 BigInt 算 —— 因为 q_k 按 φ^k 增长，第 40 项就已经超出双精度能精确表示整数的范围。

最后一列 q·‖qα‖（等于 q²·|α − p/q|）是这条数列真正的主角： 它永远落在 1/φ² = 0.38197 与 1/φ = 0.61803 之间，来回震荡， 而它的上极限恰好是 1/√5 = 0.4472136 —— 这正是 ν(φ) = √5 的另一种写法。 换句话说：表里那 14 个数没有一个等于 0.4472136，但它们的聚点只有一个，就是它。

自己试：换一个 α，换一个穷举范围

选一个 α，把 Q 以内的每一个分母都试一遍（朴素穷举）， 再和连分数给出的收敛子对账。两者必须给出同一批最佳逼近 —— 如果对不上，就是有一边错了。

贰 · 把「能多接近」做成一个数

上面那条不等式说的是「至少有一个 q 使误差掉到 1/q² 以下」。但有些数做得更好， 有些数做得更差。要把这个差别变成一个可比的数，就把不等式里的指数抠出来：

ν(α) = limsup_{q→∞} ( q · ‖qα‖ )⁻¹ ‖x‖ = 到最近整数的距离

分母里的 q·‖qα‖ 就是收敛子表最后一列那个量。它的上极限的倒数 就是 ν：ν 越大，这个数越容易被逼近；ν 越小，越难。 Hurwitz 定理（1891）给了一个下界：ν(α) ≥ √5 对一切无理数成立， 而这个 √5 不能再大 —— 黄金比例 φ 恰好取到等号。

各 α 的难度 ν（对数刻度），红点 = 上极限被小 q 污染的量

十个 α 的连分数头与难度

注意 φ 那一行：连分数全是 1，而 1 是连分数能取的最小正整数。 这是「最难」的全部原因 —— 部分商越小，收敛子爬得越慢，q·‖qα‖ 就掉不下去。 ν 有限 ⟺ 部分商有界：二次无理数周期 ⇒ 有界 ⇒ ν 有限； 而 Liouville 数的部分商可以任意大 ⇒ ν = ∞。

叁 · 一个容易算错的极限

ν 的定义里藏着一个陷阱：它是 limsup，是 q → ∞ 的上极限。 如果你偷懒，直接把 q ≤ Q 全范围里 q·‖qα‖ 的最小值取出来求倒数， 你得到的不是 ν，而是一个纯属虚构的数。

φ 的 q·‖qα‖ 随 q 的分布：小 q 给出一个假的极小值

具体地：φ 在 q = 1 处 ‖φ‖ = |φ − 2| = 0.382，于是 1/(1 × 0.382) = 2.618 = φ²， 比真正的 ν = 2.236 还大。取"全范围最小"得到的永远是 2.618，而不是 √5。

这条不是编出来的例子 —— 它是本装置第一版实现真的算出来的错数。 当时 ν(φ) 报 2.618，看着还挺像个真结果。发现它的办法只有一个： 拿一个答案已知的对照组去撞（φ 的真值是 √5），撞不上才回去查定义。 修法是只在尾部窗口上取最大值，并把「全范围值」单独留着当反面对照。

肆 · 二次无理数有一条完整的规律

√2、√3、√5 … 这些数的连分数是周期的（Lagrange 定理）， 所以它们的部分商有界，ν 有限。那么 ν(√n) 到底等于多少？

ν(√n) = 2√n 对一切非平方正整数 n 成立

把 2√n 和 ν(φ) = √5 放在一起看：最接近 φ 的 √2 也有 ν = 2.828， 是 √5 的 1.265 倍。也就是说 φ 不只是"最难"， 它还比所有二次无理数都难 —— 而且难出了一整个数量级的差别（n 越大越容易）。 原因是周期部分商里有比 1 大的数，而 φ 的部分商只能取到 1。

伍 · 在 √5 与 3 之间，难度只能取离散的值

ν 能取哪些值？直觉上应该是个连续区间。但 Markov（1879）发现了一个反直觉的事实： 在 [√5, 3) 这一段里，ν 只能落在一串离散的点上：

ν_m = √(9m² − 4) / m m 取遍 Markov 数 1, 2, 5, 13, 29, 34, 89, …

第一个点是 m = 1 给出 √5（就是 φ），第二个点是 m = 2 给出 2√2（就是 √2）。 而 3 以上才是连续段。也就是说：难度的谱是断的， 而且断点之间的空隙里没有任何数能取到。

谱点表

实测的 ν(√2) = 2.8284271247 精确落在第 2 个谱点上（m = 2），距离 4.44e-16 —— 机器精度。 这不是巧合：√2 的连分数 [1; 2, 2, 2, …] 正是 Markov 数 m = 2 对应的那条周期。

谱的另一端：逼近指数

ν 刻画的是「最接近的那一档有多接近」。还有一个更粗的量：逼近指数 μ —— 满足 |α − p/q| < 1/qμ 的 q 到底有没有无穷多个。 做法是数个数：把 Q 以内满足条件的 q 数出来，看这个计数随 Q 涨还是封顶。 涨 ⇒ 指数至少是 μ；封顶 ⇒ 指数小于 μ。

φ 的计数：满足 |α − p/q| < 1/qμ 的 q 的个数 vs Q

μ = 2 那条线一直涨，μ = 2.5 那条一动不动 —— 分界精确落在 μ = 2。 这不是 φ 的性质，是所有代数无理数的性质（Roth 定理，1955，Fields 奖）： 它们的逼近指数恰好是 2，一个不多。而 Liouville 数的指数是 ∞， 那才是"ν = ∞"那一头 —— 它需要专门构造，不能靠运气碰上。

陆 · 换一副眼镜：几乎所有数长什么样

前面几章问的是「某个特定的数」。现在把问题反过来： 随便抓一个数，它的部分商长什么样？ 答案出奇地干净 —— 部分商等于 k 的概率是 log₂(1 + 1/(k(k+2)))（Gauss 1797 年写下、Kuzmin 1928 年证明）。 这是概率论里最反直觉的分布之一：P(k = 1) ≈ 0.415，而 P(k = 1) 在"均匀随机"下应该是 0.5。

这个分布收敛得多快？把全变差距离（TV）乘上 √N 画出来 —— 如果它是一条水平线，收敛率就精确是 1/√N。实测它不是水平线，而是在 1.24 与 2.15 之间起落 （最低点出现在 N = 10⁵，之后还回升了一点）。换算成有效幂指数是 α ≈ 0.56–0.58： 与 1/√N 同量级，但不是精确的 1/√N。这条"起落"本身就是单轨道测量涨落的量级。

两个常数

Khinchin 常数：几乎所有的 α，部分商的几何平均收敛到 2.6854520010…。实测 2.6748（10 个 α 的几何平均，相对差 0.40%）。

Lévy 常数：几乎所有的 α，q_k^{1/k} 收敛到 e^{π²/(12 ln 2)} = 3.2758229…。但 φ 是例外 —— 它的 q_k^{1/k} → φ = 1.618，因为 φ 的连分数全是 1。 这正是"几乎所有"这个词的代价：定理对每个例外都闭一只眼，而例外里恰好坐着主角。

柒 · 两个精确的结构定理

三距离定理（Sós 1958 / Surányi）：把 {α}, {2α}, …, {nα} 排成一列， 它们之间的间隙最多只有三种长度，而且第三种等于前两种之和。 这不是"大约"，是精确的。

Farey 序列：分母 ≤ n 的全部既约分数从小到大排。它的长度有一个精确的闭式， 相邻两项之间有一个精确的判据：

|F_n| = 1 + Σ_{k≤n} φ(k) b·c − a·d = 1（相邻项）

同一个结构还有一副面孔：Stern–Brocot 树。每个既约分数在这棵树里有一个深度， 而深度精确等于它的连分数部分商之和减 1 —— Σa_i − 1。 555 个分数（p, q ≤ 30）全部吻合，零例外。 于是「连分数」和「二分搜索树」原来是同一件事的两种写法。

捌 · 穷举的墙

ν 定义在 q → ∞ 的极限上。如果只会穷举，那就得把 q 一个一个试过去。 问题是：这条路的代价是线性的，而你要的那个极限是无穷的。

穷举到 Q 的耗时（对数刻度，实测 + 线性外推）

本机实测吞吐约 2.0×10⁻⁶ 毫秒 / 个 q。按这个速度，穷举到 Q = 10¹⁵ 要 约 6.3×10⁻⁵ 年（半小时），到 10¹⁸ 要 63.4 年。 更要命的是：就算你穷举到 10¹⁸，你拿到的也只是"到目前为止"的值， 不是极限 —— 因为下一个 q 可能给出更大的项。

本页对二次无理数改用周期结构精确求解（连分数的周期是有限的， 周期内的递推可以迭代到不动点），正是为了绕开这堵墙。 对非周期的 α 则改用收敛子尾部窗口，并把窗口边界明确写在边界段里。
