02变化机制 / FOUR FORCES

不是每种变化，
都朝着同一个方向。

把频率变化拆成过程，才看得清一条曲线为什么弯向那里：有的机制改变抽样前的平均值，有的改变抽样的偶然幅度。

01 / DRIFT

繁殖抽样会改频率

下一代从亲代基因库抽取 2N 个等位基因。即使 A 与 a 适合度相同，有限次抽样也会让实际频率上下波动；群体越小，单次抽样的相对影响越大。

02 / SELECTION

选择改变抽样前的权重

每种基因型按适合度贡献下一代：wAA=1+s、wAa=1+hs、waa=1。即使 s 很小，它也要与随机漂变共同作用。

03 / MUTATION

突变能补回变体

双向突变把 A 变成 a，也把 a 变成 A。它可能让已经很少见的变体重新出现；在这个模型里两个方向使用相同的突变率。

⇄
04 / GENE FLOW

迁入把邻近频率带来

繁殖前将本地与固定来源群体按迁入比例混合。高频 A 群体的持续迁入，能把本地频率推离原先的方向。

05 / BOTTLENECK

一次骤减，会留下抽样痕迹

瓶颈本身不挑选某个等位基因，但小群体抽样会增加频率变化幅度。数量恢复不会自动恢复曾经丢失的变体；保留下来的频率还会继续漂变。

基因型选择 → 双向突变 → 与来源群体混合 → 从 2N 个等位基因中二项抽样。一次瓶颈只改变指定那一代的目标群体大小。

03怎样读一条轨迹 / READING THE RUN

把一次结果，
放回重复之中。

单条路径展示可能发生什么。多次独立重复则展示在这些假设下，结果大致落在哪些范围；两者回答的不是同一个问题。

问 / ONE LINEAGE

这条谱系的结局是什么？

一条亮线可能很快固定、偶然丢失，或在观察期内继续分离。换一条追踪谱系，不改变其余模拟。

问 / THIRTY-TWO REPEATS

固定、丢失和分离各有多少？

柱状分布统计当前世代的 32 个重复群体。它会随查看世代改变，也会随重新抽样改变。

问 / SAME RANDOM STREAM

改一个条件，差异来自哪里？

滑块变动时保留随机数序列，方便比较同一批抽样在另一组权重下如何走。独立重复不是现实群体，也不是预测区间。

04模型边界 / A MODEL, NOT A POPULATION

这是一台
理想化的抽样机。

模型采用单个位点、两个等位基因、二倍体、常态有效群体大小固定、世代不重叠、随机交配的 Wright–Fisher 结构。每代把适合度、双向突变和单向迁入作用于抽样前的频率，再从 2N 个基因拷贝中进行二项抽样。

现实中的群体有年龄结构、空间分布、近亲繁殖、性别差异、连锁、复杂遗传背景和变化的繁殖成功率。真实群体的有效大小也可能显著小于可见个体数。此处的“选择系数”不是任何具体物种的实测值。

频率 p 的杂合度读数 2p(1−p) 是在随机交配假设下对一个二等位位点的期望；它不是观察到的实际基因型计数。中性、无突变且群体大小固定时，理论期望频率保持不变，但各条有限群体的轨迹仍会分开。
