# 创作破局记录：从“调参看结果”到“改写历史”

这次新增作品不是为现有展厅再补一个学科，而是刻意改变互动科学作品的基本语法。

## 1. 旧作品容易固化在哪里

现有集合的题材跨度已经很大，但不少作品仍会回到相似的交互骨架：

1. 标题与概念说明先出现；
2. 用滑杆、按钮或标签页调整参数；
3. Canvas / SVG 展示结果；
4. 最后给出结论、证据与模型边界。

这个结构在科普上可靠，却容易把用户固定为“调参观察者”。学科换了，认知动作却没有换：用户知道自己正在操纵什么参数，也大致知道应该看什么结果。

## 2. 三个差异化方向

### A. 把页面做成仪器，而不是说明书

先不给完整解释，只给可操作的测量界面。用户通过读数、误差、重复实验和异常现象自己逼近规律。说明退到第二层。

### B. 把单人调参改成多代理证据冲突

让不同观察者只拥有局部信息，并允许证据互相矛盾。用户的任务从“找正确参数”变为“判断谁看到了什么、哪些证据独立、哪些只是重复传播”。

### C. 把当前状态改成可编辑的时间

把历史本身变成界面对象。用户可以倒回过去、从中途分叉、保留旧未来，再比较不同路径抵达相同当前条件时的差异。

## 3. 选定方向

《迟滞之痕》采用 **A + C**：

- 页面是一台连续工作的磁滞记录仪，不使用传统卡片式参数面板；
- 用户直接拖动材料区域来“写”外场历史；
- 时间带可以回放真实状态快照；
- 从过去继续操作会生成新分支，同时保留旧未来为 ghost branch；
- 用户可以标记一个 `(H, M)` 状态，沿另一段历史回到相近 `H`，直接测出 `ΔM`。

核心命题不是“磁滞回线长什么样”，而是：

> 当前输入不足以描述当前状态，历史也属于状态。

## 4. 技术实现

模型采用教学化 Preisach relay ensemble：

- 1320 个双稳态单元；
- 每个单元具有 `α` / `β` 两个翻转阈值；
- `Float32Array` 保存阈值，`Int8Array` 保存状态；
- 状态更新只在跨越阈值时翻转，否则保留历史状态；
- 宏观磁化 `M` 为所有单元状态的平均。

交互层不是只保存当前参数，而是保存事件历史与状态快照：

- timeline scrub 会恢复过去的真实材料状态；
- 在过去继续拖动时，后续历史不会被静默覆盖，而是变为 ghost branch；
- recorder 同时绘制当前分支和旧未来；
- pin comparison 在相近外场处计算两段历史的 `ΔM`。

作品保持单 HTML、离线运行、无外部运行时依赖，继续兼容展厅现有的独立分发方式。

## 5. 与以往设计思路的关键差异

| 维度 | 常见旧结构 | 《迟滞之痕》 |
| --- | --- | --- |
| 用户角色 | 调参数、看结果 | 写历史、改过去、比较分支 |
| 信息结构 | 先解释，再验证 | 先操作仪器，解释藏在背面 |
| 主要对象 | 当前参数 | 历史路径 |
| 可视化 | 独立图表/面板 | 材料、记录图、时间带组成一台连续仪器 |
| 状态管理 | 当前值驱动 | 快照历史 + 可回放 + 分叉 |
| 科学体验 | “参数改变结果” | “相同当前条件也可能因历史不同而不同” |

这次变化的目标不是更炫，而是让用户执行一种此前集合里较少出现的科学动作：**把历史当成实验变量。**
