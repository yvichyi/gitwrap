# 未完成的织物

作品入口：[未完成的织物.html](../未完成的织物.html)

## 创作诊断

以当前 main 的 43 件作品为基线。《此刻》《雨的去路》等以既定科学机制为中心；即使《无名定律》把规律隐藏起来，主要任务仍是操作仪器、观察和验证。共同的表达语法是标题/命题、控制区、现象、解释、模型边界。问题并非每件作品都一样，而是参与者多数时候仍在探索作者预设的对象。

考虑的三个方向：

- **未完成的织物**：从解释机制转向共同制作；输出可以带走的矢量纹样。选定并实现。
- **隔墙来信**：通过递送次序与延迟推进信息不对称的叙事。
- **消失的字典**：以删词、重组和排版作为语义压缩的操作材料。

本作把“规则”变成可创作的材料。用户确定若干局部针法，算法完成剩余约束，冲突促使作者取舍，而非等待预设结论。作品不预设成功分数或唯一正确图案。朱砂、靛蓝、布边与排印取代深色仪表视觉；说明延后到折叠区。

## 完整行为

12 × 12 封边图案，八种偶数度针法。可固定/拆除局部、续织、禁止针法、故意制造冲突、撤销/重做、换三种配色。支持浏览器本地草稿、严格校验的 JSON 织谱导入导出、320 mm SVG 图案下载。所有运算本地完成；单 HTML 不依赖网络或构建工具。键盘方向键、Enter、Delete 可完成核心编辑，320 px 起不出现横向溢出。

## 算法与工程

- 完整针法集：将未知接缝建成图，已固定的线头成为各顶点的奇偶约束。在生成树外随机选边，再从叶节点消元求树边；每个分量根节点检查剩余奇偶值。复杂度随顶点与接缝数线性增长，避免完整针法下不必要的指数搜索。
- 禁用针法：位集表示候选集合，接缝约束传播、最小剩余值选择、带种子洗牌及回溯。独立报告预算耗尽和已证无解。
- 一个纯 generator 同时用于 Blob Worker 和主线程合作式分片后备；每次编辑取消旧任务，用任务编号丢弃过时结果。
- 织谱是唯一创作状态：固定点、允许针法、种子、配色。撤销恢复织谱并确定性重算；SVG 与界面共用同一针法绘制逻辑。
- 接入 catalog.json，再运行生成器更新展厅及逐件目录；修复主题数与旧浏览器测试作品数的硬编码。未改动原有作品或 Python CLI。

## 边界

这是图形接缝创作，不是物理织造模拟；无纤维受力、织机生产或单一闭环保证。红框不是最小不可满足核。限制针法后的搜索有 30,000 次选择预算。默认浏览器草稿仅保留最近状态，完整撤销历史不跨刷新保存。视觉工作台仍保留工具区，因此本次转变主要在作者角色、生成机制与可带走的产物，不把它描述成完全抛弃交互界面的作品。
