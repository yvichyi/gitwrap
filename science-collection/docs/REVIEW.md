# 检查与优化记录

## 1. 项目定位与结构

原包仅含 41 个 HTML，总计 4,458,372 字节，未提供 README、目录页、测试配置、源码工程或许可证。41 页均设置中文页面语言和移动端 viewport；静态扫描未发现重复 ID 或行内 JavaScript 语法错误。脚本与样式均在文件内，绘图使用 Canvas 或 SVG，部分作品使用 Web Audio。

共同结构包括模型规则、可调条件、结果显示、证据核对与“没做到什么”。作品可以单独分发。风格并不完全统一：既有标签页形式的数值研究，也有实验台、全屏叙事和入门小游戏。为保持这几种阅读方式，本次没有抽出统一前端框架或改变文件名。

《多数的环》的“展厅索引”原本指向缺失的 `index.html`。本次补上这个已有入口，利用 `catalog.json` 生成静态展厅和逐件目录；搜索与分类不发网络请求，禁用 JavaScript 后仍可浏览完整列表。

## 3. 复现能力需要区分三个层次

1. **交互模型：** 在浏览器中真正执行，可以改变参数、逐步运行；本次验证包含实际加载、标签页切换和修复相关交互。
2. **内嵌批量结果：** 原页中保留历史生成的数据。例如 `__ANALYSIS__`、`__SAT_DATA__`、`__AW_DATA__`、`__BB_DATA__` 等全局对象。页面展示这些数字，不代表每次打开都重新跑完整批量实验。
3. **一般科学或数学结论：** 依赖明示假设、外部文献或证明。有限规模的动画、计数与比较可以解释机制，却不自动证明更一般的命题。

16 页具有三段行内脚本，通常包含模型核心、预计算结果和界面逻辑：《与非之上》《临界的形状》《可学之界》《四二六七》《差之毫厘》《平方之前》《异步之墙》《忘记起点》《搬了多远》《无序不可能》《比特之漏》《熵之彼岸》《纸带之上》《逼近之极》《链之宿命》《马后炮》。顺序因作品而异。

原页引用或注释中出现 `core.js`、`analysis.json`、`calibrate.js`、`verify.js`、`bench.py` 等工程文件名；压缩包并未附上独立文件。内嵌核心能够继续运行，但缺少原始批量生成器、命令、环境、随机种子约定和完整断言，不能据此宣称已重建原作的全部数值研究。

`docs/source-manifest.json` 记录上传 ZIP 与原始 HTML 的哈希，可追溯来源。该记录是来源证据，不会补齐缺失的科学验证。

## 4. 内容上值得继续校准的表述

这些是后续编辑建议，本次保留原文与原始实验数据，不假定替作者完成数学证明。

| 作品 | 原文例子 | 需要澄清的区别 | 建议改写方向 |
| --- | --- | --- | --- |
| 纸带之上 | “那不是代码没写好，那就是这堵墙本身”“加预算解决不了它” | 两条证书规则在有限预算下未判定，说明当前方法覆盖不足；不能仅由实验推出某台机器不停机或一般不可判定性 | 明示当前规则与已测预算的局限，将一般停机问题的不可判定性单独归于数学证明 |
| 异步之墙 | 标题“把 FLP 不可能性算出来”及总结“把这条定理算了出来” | 某类有限协议的穷举可以精确判定该模型，FLP 涵盖更一般的确定性异步协议；具体反例与通用证明范围不同 | 保留反例与调度实验，将其定位为理解 FLP 的有限模型证据 |
| 临界的形状 / 忘记起点 / 四二六七 | 有限尺度拟合、七次洗牌、约 4.2667 的阈值 | 样本规模、距离指标、渐近理论与误差范围共同决定含义 | 在关键数字旁标注模型、规模、指标与误差来源，避免只展示一个醒目数 |

各页已存在不同程度的边界说明。上述建议是把限定条件移到关键主张旁，使读者在看到结论时就能知道范围。

《似是而非》是值得保留的正面例子：虽然测试器允许输入任意大小的整数（实际输入上限 300 位），`testerRun` 已按已知数值范围区分“素数（证明）”与“大概是素数”；例如 2¹²⁷−1 的预设也明确说明固定 13 底无法在该范围给出证明。这里不应误报为无范围的确定性检验。

## 5. 后续优化优先级

| 优先级 | 工作 | 收益与完成条件 |
| --- | --- | --- |
| P1 | 找回历史计算脚本、参数与种子 | 为 16 个含预计算数据的作品提供来源、算法版本、计算命令和可重跑的小规模对照；需要作者补充原工程 |
| P1 | 校准关键结论的范围 | 区分有限反例、算法预算、渐近理论与一般证明；以逐条主张核查作为验收 |
| P2 | 将昂贵实验移到 Worker 或分块调度 | 已测到主线程负载或交互卡顿后再做；保留种子、数值结果与取消操作的一致性 |
| P2 | 统一补充可访问性 | 检查 Canvas 的文字等价结果、键盘流程、焦点提示、动态播报和降低动态效果；需独立辅助技术验证 |
| P3 | 从完整工程生成单文件发行版 | 若未来频繁修改，可拆出核心、UI 与数据作为维护源码，再生成 HTML；单文件产物保持独立可用 |

当前集合约 4.25 MiB，没有重型运行依赖。静态托管时的 gzip/Brotli 缓存通常比引入打包框架更有直接收益；需在具体托管平台配置后才能验证。本次未做部署，也未声称改善线上指标。
