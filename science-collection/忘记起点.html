洗牌，与「多久才算真的随机」

壹 · 一次洗牌等于没洗

一次 2-洗牌的动作是：给每张牌独立抛一枚硬币，硬币为 0 的牌按原顺序放到最上面， 为 1 的按原顺序接在下面。所以洗完之后，这堆牌长什么样，完全由那 n 枚硬币决定。 硬币只有 2ⁿ 种结果，于是输出的牌堆最多也只有 2ⁿ 种。

一次 2-洗牌 ⟺ 每张牌拿一个 k 位随机标签，按标签从小到大把牌收起来 k 次 2-洗牌 ⟺ 给每张牌一个 [0, 2ᵏ) 的均匀标签，按标签做一次稳定排序 ⟺ P_k(σ) = C(2ᵏ + n − 1 − r(σ), n) / 2ᵏⁿ （r(σ) = σ 的上升段数）

贰 · 那根箭头

洗牌是一根多对一的箭头：2ᵏⁿ 个标签向量进去，n! 个排列出来。 每个排列的原像个数叫它的纤维。纤维不是均匀的 —— 它只依赖排列的上升段数， 而且随上升段数单调递减。

纤维大小 N_j = C(2ᵏ + n − 1 − j, n) j = 下降数 概率 P_k(σ) = N_{desc(σ)} / 2ᵏⁿ 恒等式 Σ_j A(n, j) · N_j = (2ᵏ)ⁿ （A(n,j) = 欧拉数：恰有 j 个下降的排列数）

9

纤维大小与排列数：两条曲线错位（对数刻度）

蓝线是"每个排列被多少种硬币结果命中"，紫线是"有多少个排列落在这一格"。 输出分布不匀的全部原因就在这两条线的错位上。

伍 · 三个价钱

同样是"把牌弄乱"，动作集不同，价钱差得很远。这里摆三条链： 交错洗牌、随机对换（i, j 独立均匀取自 [n]，含 i = j 的原地不动）、 顶牌插回（把最上面那张插到 n 个位置之一，含插回原位）。

捌 · 特征值

2-洗牌链的特征值是 1, 1/2, …, 1/2ⁿ⁻¹，其中 1/2ⁱ 的重数等于"恰有 n − i 个轮换的排列数"。 这条谱有两个后果：收敛速度只由 λ₂ = 1/2 决定，而它与 n 无关。
