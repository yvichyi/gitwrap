随机 3-SAT 的相变，与它身边那道最陡的悬崖

随机 3-SAT 只有一个旋钮：子句数 m 与变量数 n 之比 r = m/n。 把 r 从小往大拧，同一类公式会从"几乎总可满足"翻到"几乎总不可满足"。 翻面的位置落在 4.2667… 附近——而就在那一点上，求解它变得最贵。 本页从零搭了一台 CDCL 求解器，用它把这条曲线亲自量了一遍， 顺便把"测量本身有多可信"也一并量了。

01

一个旋钮，两个世界

一个 3-CNF 公式是若干条子句的合取，每条子句里恰好三个文字（变量或它的否定）， 例如 (x₁ ∨ ¬x₄ ∨ x₇)。它可满足，意思是存在一组 0/1 赋值让每条子句都至少有一个文字为真。 随机生成的办法很朴素：每条子句随机挑 3 个互不相同的变量，每个独立地以 1/2 概率取反。

这个模型里没有任何可调的结构——没有社区、没有隐藏规律、没有难度梯度。 唯一的自由度就是子句的数量。而恰恰是这个最贫瘠的模型，给出了计算复杂性里最锋利的一条经验边界。

02

从零搭一台 CDCL 求解器

现代 SAT 求解器不是"猜遍所有可能"，而是三件事的组合： 单元传播（一条子句只剩一个未定文字时，它被迫取真）、 冲突分析（从矛盾出发，反推出导致矛盾的最小前提，把它作为新子句学下来）、 VSIDS（谁参与冲突多，下次优先猜谁）。 下面这台是完整实现：两观察文字、1UIP 学习、相位保存、Luby 重启、按 LBD 删句。

它可以逐微步播放。每一步要么是"传播到底后做一个猜测"，要么是"撞上冲突、学一条子句、回跳"。

这不是测量错误，是有限尺寸效应。任何相变在有限的 n 上都"糊"成一段宽度为 w(n) 的过渡带， 你测到的交点是这条带的中线，它只有在 n→∞ 时才落到真实阈值上。 对 2-SAT，w(n) 宽得离谱——理论结果是 ∼ n−1/3；对 3-SAT 窄得多。 所以"我测到 2-SAT 阈值是 1.26"这句话是对的，同时"2-SAT 阈值是 1"这句话也是对的，两者不冲突。

峰是算法的属性，不是问题的属性

我原本以为"难度在相变点上达到峰值"是相变的普遍后果。数据说不是。 3-SAT 有那座山，是因为我们没有多项式算法——求解器只能真的去搜，而搜索的代价在临界点上最高。 2-SAT 有同一个相变、同样锋利的概率曲线，可一旦换用蕴涵图 SCC（线性时间），峰当场消失； 连朴素 DPLL 都因为单元传播太有效而看不到峰。 相变是公式的性质，尖峰是"算法不够强"的性质。这条曲线的形状，量的是我们离多项式算法有多远。

05

冻结：解被一根根钉死

再换一个视角看同一个转变。一个变量叫冻结，如果它在公式的所有解里取值都相同。 冻结比例从 0 涨到 1，意味着解空间从"一团自由的云"收缩成"一个孤零零的点"。

冻结变量比例 vs r（只统计可满足实例）

这条曲线的终点是断的，不是画漏了：r 一旦越过阈值，一个解都没有， "在所有解里取值相同"就成了空话。所以这一节只在阈值左侧有定义—— 这本身就是相变的另一种说法。

07

这些数字凭什么可信

本页所有结论都出自自己写的代码，所以"可信度"这件事必须单独交代——不能只靠"跑通了没报错"。 模型层是三套互相独立的实现：

  • 暴力枚举：把 2n 个赋值全试一遍。慢，但没有任何可以搞错的地方。
  • 朴素 DPLL：递归 + 全扫描单元传播。与 CDCL 共享的代码为零。
  • 2-SAT 蕴涵图 SCC：Tarjan 线性算法，与"搜索"是两种完全不同的数学。

三者在成千上万个随机实例上逐例对账。CDCL 报 SAT 时，模型还要被逐条子句验算； 它每学到一条子句，也要验证这条子句被原公式的所有解满足（对小子句穷举全部解来验）。 求解器还必须在六种配置下给出完全相同的答案——否则消融实验测的就是 bug 而不是算法。

自检与验证的实际规模

必须说清楚的边界

  • n 只做到 200。再往上单次求解动辄数秒到数十秒，扫描量撑不住。 所以本页测到的交点全部高于 4.2667，而且越大的 n 越靠近它——这是趋势，不是收敛证明。
  • "未判定"绝不混进"不可满足"。求解器有冲突预算，超预算的实例单独统计并在图上标出。 把超时当成 UNSAT 是这类实验里最容易犯、也最难被发现的错误。
  • 4.2667 不是定理。它是 1RSB 空腔法的公认值；k=3 的严格证明至今未闭合。 本页把它当"参照线"，不当"标准答案"。
  • 交点的误差是有限的。每个点用数百个实例，交点由线性插值得到， 真实的统计不确定度在 ±0.02 量级。表中给出了实例数，可以自己判断。
  • JS 比 C 慢得多。这台求解器在 n=200、r≈4.27 上中位耗时约 250ms， 同规模下 MiniSat 量级是十几毫秒。本页所有"难"的判断都是相对的，不是绝对的。

还没做的事

相变点附近的解空间结构（聚簇、凝聚、1RSB 复本对称破缺）这一层完全没有触及—— 那需要按解的数量加权采样，是另一套机器。另外，n 再大两三个数量级才有可能 把 4.2667 逼到一个真正有说服力的精度。

模型　随机 k-SAT（每条子句 k 个互异变量，各自以 1/2 取反）。 求解器：两观察文字 + 1UIP 冲突分析 + VSIDS + 相位保存 + Luby 重启 + LBD 删句。 所有实例由固定种子的 splitmix32 派生，逐例可复现。

参照　阈值 4.2667 出自 1RSB 空腔法（Mézard–Parisi–Zecchina 2002；Mertens–Mézard–Zecchina 2006）； 大 k 的严格证明见 Ding–Sly–Sun；2-SAT 阈值 = 1 及标度窗口 ∼ n−1/3 见 Bollobás–Borgs–Chayes–Kim–Wilson 2001。 易-难-易现象见 Mitchell–Selman–Levesque 1992。
