# 互动科学装置

从 `拥堵之波.zip` 整理出的 **41 件单文件互动作品**。覆盖数学、计算机、物理、天文、地球科学、生命科学、测量和社会选择。作品以“改变条件 → 观察结果 → 检查证据与边界”为共同阅读方式。

打开 [作品展厅](index.html)，按主题浏览或搜索；查看 [逐件目录](docs/CATALOG.md) 获取每件作品的核心问题、方法、建议操作和模型边界。

## 怎样运行

直接双击 `index.html` 或任一作品 HTML 即可。没有运行时 npm 依赖，也不需要后台、账户或外部脚本；音频作品需要点击后启用浏览器音频。文献链接在主动点击时需要联网。

也可以使用本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。可将同一目录交给任意静态托管服务；本项目尚未配置或执行线上部署。

## 四条阅读路线

1. **第一次接触：** 先踢掉谁？ → 马后炮 → 两处栖身 → 与非之上。从具体选择进入算法与机器。
2. **波和空间：** 拥堵之波 → 驻波之间 → 长浪抵岸 → 共转之处。比较传播方向、空间边界与稳定性。
3. **测量不等于真相：** 同影异物 → 切片之前 → 震源的坐标 → 半信半疑 → 无原稿。观察数据不足、先验、噪声和相关证据。
4. **随机不等于无规律：** 未选之路 → 偶然的谱系 → 忘记起点 → 似是而非 → 比特之漏。分别看探索、漂变、混合、概率保证与确定性混沌。

## 目录结构

```text
index.html               离线展厅：分类、搜索与作品入口
catalog.json             41 件作品的人工归纳信息，目录的维护入口
*.html                   原有单文件作品，保留原始文件名与相互链接
docs/CATALOG.md          逐件分析表，由 catalog.json 生成
docs/REVIEW.md           检查发现、已做优化与后续优先级
docs/VALIDATION.md       本次实际验证范围和结果
docs/source-manifest.json 原压缩包及 41 件原始文件的 SHA-256
scripts/build_catalog.py 生成展厅和目录；支持 --check 检查是否过期
scripts/check.py         检查覆盖、链接、元数据、ID、外部依赖及 JS 语法
scripts/browser-check.cjs 浏览器加载、标签页与优化回归检查
```

《似是而非》的原文件名是 `sishierfei.html`，《无原稿》是 `无原稿_最终.html`。保持名字有助于对照原始压缩包和避免破坏已有引用。

## 维护与验证

新增或修改归纳信息时，编辑 `catalog.json`，然后运行：

```bash
python3 scripts/build_catalog.py
python3 scripts/check.py
```

静态检查需要 Python 3.10+ 和 Node.js 18+。浏览器检查需要额外安装开发依赖，作品本身不需要这些依赖：

```bash
npm ci
npx playwright install chromium
npm run test:browser
```

已有系统 Chromium 时，可用 `CHROMIUM_PATH=/usr/bin/chromium npm run test:browser`。浏览器检查自行启动临时本地服务器，并将报告保存到被 Git 忽略的 `artifacts/`。

归纳文本与当前页面共同描述一个教学实验集合。本次检查未重新运行原作全部历史穷举或蒙特卡洛研究；详见 [复现边界与优化建议](docs/REVIEW.md)。原压缩包未附许可证，整理版本不擅自添加授权条款。
