03 计算说明 / MODEL NOTES

一间理想房间，
一条有限的答案。

页面里的每个模式都来自长方体边界条件下的解析解。我们把许多模式加在一起，得到相对声压；这是一台用来理解规律的模型，不是房间测量仪。

共振频率

fn = c2 √[(nx/Lx)² + (ny/Ly)² + (nz/Lz)²]

c = 343 m/s；nx, ny, nz 为非负整数（不能同时为 0）
空间形状

φn(x,y,z) = cos(nxπx/Lx) cos(nyπy/Ly) cos(nzπz/Lz)

φ 接近 0 的位置是节点；绝对值大的位置是波腹。
多个模式叠加

H(r,s;f) ∝ Σn φn(r) φn(s) / (fn² − f² − i f fn/Qn)

扬声器位置 s 会影响激发强度；听音位置 r 会影响听到的强弱。
模型边界

它省略了真实房间里的很多东西。

房间被视为长方体，墙壁完全刚性；模式衰减在整个频段采用同一个 T60。页面叠加 220 Hz 以下的模式，声场图显示耳朵高度附近的水平切片。所有声压均按同一房间的空间均方值归一化，因此 dB 只表达位置差异，不是声压级或音箱响度。

门窗、斜墙、家具、墙体损耗、扬声器指向性和直达声都不在模型中。真实房间中的每条共振峰都可能偏移，平面图也不会代替现场测量。
