随机映射 · 你总会走进一个环

给 n 个点各配一个像，配法完全随机，就得到一张随机映射。 从任意一点出发反复迭代，走过的点一旦重复，就再也回不到新的地方—— 于是每个点最终都落进一个环。这张图由若干个 ρ 形拼成：一条尾巴接一个环。 这一页从零实现整套结构分解，把 n ≤ 8 的全部 8⁸ 个映射逐个走一遍， 再把闭式推到 n = 10⁸，和 Flajolet–Odlyzko 的常数逐条对账。 结论是：尾巴和环一样长，都是 √n 量级；但环永远比尾巴多恰好 1。

壹重逢：一个具体的长什么样

左边这张图就是一个真实的随机映射：每个点伸出一根箭头指向它的像。 环画成圈（砖红），挂在环上的树画成链（青蓝），箭头方向一律指向环。 点任何一个点，它走的路会被点亮——它一定会走进某个环，然后绕着走。 这条路的长度分成两段：进环之前走了 tail 步，进环之后要绕 cycle 步才回到起点。

叁恒等式：环永远比尾巴多 1

尾巴和环各自的期望都趋于 √(πn/8) ≈ 0.6267√n，两条曲线在对数坐标里几乎重合。 但它们的差不是 0，而恰好是 1 —— 而且不是渐近，是对任意 n 精确成立：

E[环长] − E[尾巴] = 1   （n = 1, 2, 3, … 全部成立，残差 ~10⁻¹²，纯浮点噪声）

下面是三路独立证据摆在同一个横轴上：全枚举（n ≤ 8，逐个映射走一遍，不用概率论）、 闭式（n ≤ 10⁸，直接求和）、蒙特卡洛（带误差棒）。 注意大 n 上误差棒已经跨过了 1 —— 那条恒等式在那个尺度上是看不见的。

肆为什么恰好是 1：一个对称性

把行走换成等价的说法：x₀ 均匀随机，之后每一步独立均匀地掷一个点， 直到第一次撞上已经走过的点。这与「先生成整张映射再走」完全同分布—— 因为凡是第一次访问到的点，它的像都还没被掷过，独立且均匀。

设走过的不同点数是 ρ，撞上的那个旧点排在序列的第 T 位。 第 m 步才第一次重复、且撞上第 t 个旧点的概率是 (n)_m / n^(m+1) —— 对每个 t 都一样。于是：

给定 ρ = m，T 在 {0, 1, …, m−1} 上均匀  ⟹  E[T | m] = (m−1)/2，  E[C | m] = (m+1)/2  ⟹  E[C − T | m] = 1

对 m 求平均还是 1，所以 E[C] − E[T] = 1 对任意 n 精确成立。 下面左图是 ρ 的精确分布（闭式），右图是现场掷出来的「给定 ρ = m 时 T 的分布」—— 它应该是一条平线。选一个 m，按下去看。

伍对照：排列从不重逢

把每个点的像限制成双射（排列），图就碎成一堆互不相干的环，一条尾巴都没有。 你永远回到出发点，也永远不再遇见别的点。两个世界的差别是量级上的： 映射的 ρ 是 1.2533√n，排列的最长环是 0.6243n。
